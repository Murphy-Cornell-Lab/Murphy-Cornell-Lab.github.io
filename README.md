# Patrick Murphy Lab

English-language laboratory website for Patrick Murphy Lab at Cornell University.

Website: https://murphy-cornell-lab.github.io/

This repository is the public GitHub Pages deployment. The separate lab-website repository remains private.

Static HTML, CSS, JavaScript, and images. No build step is required. GitHub Pages publishes main from the repository root. Navigation uses hash routes.

News and teaching entries link to their sources. Scientific figures retain attribution. No blanket license is granted for third-party material.
